# Hoplon

Asset management system for Lakmee Exports Lanka.

- `backend/`  Django + Django REST Framework API (PostgreSQL)
- `web/`      React web app (later)
- `mobile/`   Expo mobile app (later)
- `desktop/`  PyWebView desktop wrapper (later)
- `docs/`     Project documentation

See `docs/PROJECT_DOCUMENT.md` for the full specification and roadmap.
